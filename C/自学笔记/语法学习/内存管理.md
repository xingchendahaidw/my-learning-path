**内存管理**
前面用的变量和数组，大小都是写代码时就确定的，它们存在栈（stack）上，函数结束就自动释放。
但有时候数组大小要到运行时才知道，这就需要在堆（heap）上手动分配内存。这篇讲的就是 C 语言的手动内存管理。

**栈内存与堆内存**

先搞清楚这两种内存的区别：
	栈（Stack）	堆（Heap）
分配方式	自动（声明变量时）	手动（调用 malloc）
释放方式	自动（函数返回时）	手动（调用 free）
大小限制	较小（通常几 MB）	较大（取决于系统内存）
速度	快	稍慢
典型用途	局部变量、函数参数	运行时动态大小的数组
void foo() {
    int a = 10;                          // 栈上，函数结束自动释放
    int arr[100];                        // 栈上，函数结束自动释放
    int* p = malloc(100 * sizeof(int));  // 堆上，需要手动 free
    free(p);                             // 手动释放
}
为什么需要堆内存？两个常见场景：
    1.数组大小运行时才知道：比如先读入 n，再创建大小为 n 的数组
    2.数据需要跨函数使用：栈上的变量在函数返回后就没了，堆上的不会

**malloc 与 free**
malloc（memory allocate）在堆上分配指定字节数的内存，返回一个指针；用完必须用 free 释放
sizeof(int) 返回一个 int 占多少字节（通常是 4），n * sizeof(int) 就是 n 个 int 一共需要多少字节。

**calloc**
calloc 和 malloc 类似，但有两点不同：参数形式不一样，而且会自动把内存初始化为 0

**realloc**
realloc 用来调整已分配内存的大小，相当于「扩容」。一个典型场景：不知道输入有多少个数，需要边读边扩容：
realloc 会保留原有数据，如果新大小更大，多出来的部分是未初始化的。上面这个「容量不够就翻倍」的模式，其实就是动态数组（如 C++ 的 vector）的底层实现原理。
