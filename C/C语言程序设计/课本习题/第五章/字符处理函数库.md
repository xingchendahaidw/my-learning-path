## 一、逐个函数解释（ctype.h 里面这 4 个）
> 注意：`isupper()`、`islower()`、`toupper()`、`tolower()` 的参数类型是 `int`，规范上一般传 `unsigned char`，初学直接传 char 即可。

1. **`isupper(ch)`**
功能：判断 `ch` 是否为**大写英文字母 A~Z**

- 返回**非 0（真）**：是大写字母
- 返回 **0（假）**：不是大写字母
等价手写判断：`ch >= 'A' && ch <= 'Z'`

2. **`islower(ch)`**
功能：判断 `ch` 是否为**小写英文字母 a~z**

- 返回**非 0（真）**：是小写字母
- 返回 **0（假）**：不是小写字母
等价手写判断：`ch >= 'a' && ch <= 'z'`

3. **`tolower(ch)`**
功能：如果 ch 是大写字母，**返回它对应的小写字母**；不是大写，原样返回

> 
> 不会自动修改 ch 本身！所以必须写 `ch = tolower(ch);` 赋值回去

4. **`toupper(ch)`**
功能：如果 ch 是小写字母，**返回它对应的大写字母**；不是小写，原样返回

> 同样需要赋值：`ch = toupper(ch);`
